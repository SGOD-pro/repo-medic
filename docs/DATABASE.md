# SQLite and artifacts

Canonical first migration: ../contracts/sql/001_initial.sql. B owns DB writes; foundation reviews schema changes. Engine never creates another DB. One API+worker host, separate connections, foreign_keys ON per connection, WAL, busy_timeout and short transactions.

| Table | Purpose |
|---|---|
| schema_migrations | Ordered migration history |
| sessions | Token hash/access class/expiry/revoke |
| runs | Recipe/mode/state/reason, idempotency, budgets, cancellation, worker lease |
| branches | Immutable candidate lineage and current per-node state |
| reservations | Atomic pre-operation limits; reserved/settled/uncertain/released |
| operations | Submission intent, provider ID, reconcile state/checkpoint |
| model_calls | Model/config hash/usage/status, no credentials |
| events | Authoritative per-run ordered event payloads |
| artifacts | Private relative path/hash/size/provenance/retention |

State transition + associated event append is one transaction. seq = next committed seq under write transaction, not separate read-then-write. Admission unique(session_id,idempotency_key) returns existing request only on matching canonical hash. Claim/lease/cancel/finalization use conditional updates and fenced worker ownership.

Reserve worst-case known usage/cost before submitting paid work; count pending reservations toward limits. Provider operation submission intent is written before network call; provider ID recorded immediately when obtained. On ambiguous timeout, keep uncertain reservation and inspect/reconcile before considering another submission. No blind retry after restart. HostPorts calls may not hold transactions over provider calls.

Artifacts: temporary private write → fsync where supported → atomic rename → SHA256/size → register in DB → emit artifact event. Register only complete files. Startup reconciles orphan temporaries/registrations; missing/corrupt winner artifact forbids success. Filesystem+DB aren't one atomic transaction, so explicit recovery is required. JSONL is derived export from events, not a second authoritative event log.

Use integer micro-USD or Decimal for calculations; JSON/SQLite USD strings keep precision. Never binary float budget arithmetic. Time duration measurements use monotonic clock; persisted times UTC. IDs generated by owning component (opaque UUID strings recommended); unique namespaces for run/branch/op/artifact.

Migrations execute only at startup/setup under lead-controlled schema version. Don't rerun initial SQL against existing DB blindly. Tests use tmp_path/tempfile isolated databases and assert real constraints, not mocked sqlite3 return values. Backups include consistent SQLite snapshot plus artifacts; restore test before production.
